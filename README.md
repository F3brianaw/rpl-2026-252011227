## Tujuan Pembelajaran RPL

Repository ini dibuat sebagai dokumentasi pembelajaran mata kuliah Rekayasa Perangkat Lunak (RPL). Tujuan pembelajaran saya adalah memahami proses pengembangan perangkat lunak, menganalisis permasalahan pada sistem yang sudah ada, menyusun kebutuhan dan usulan perbaikan, serta menerapkan praktik kolaborasi dan dokumentasi menggunakan Git dan GitHub.

## Decision Note

Untuk Tugas 01, saya memprioritaskan perbaikan mekanisme koreksi KRS sebagai fokus utama karena mahasiswa yang mengalami bentrok jadwal setelah penyimpanan belum dapat memperbaiki pilihannya secara mandiri berdasarkan pengalaman observasi. Alternatif lainnya adalah memprioritaskan penyederhanaan navigasi evaluasi dosen, yang juga memerlukan banyak langkah berulang. Saya memilih masalah KRS karena dampaknya berkaitan langsung dengan kemampuan mahasiswa menyelesaikan proses akademik secara mandiri, sedangkan perbaikan evaluasi dosen tetap dicatat sebagai rekomendasi tambahan.
